# ExpertHub 2.0 — E-School & Consultation Platform

A **single-folder**, production-shaped full-stack application.

## 🎯 What's new in 2.0

- **Landing page** with features, pricing, testimonials, and FAQ
- **Complete auth** — register (with admin approval for experts), login, forgot/reset password, JWT + refresh tokens, change password
- **Real wallet** — top-up, ledger, course purchases debit your wallet, expert earnings credit theirs
- **Coupons** — percent or fixed, expiry, max uses, min spend, category targeting
- **Real-time chat** — typing indicator, read receipts, file attachments, presence
- **Video calls** — one-click Jitsi room per consultation
- **Full CRUD** for users, experts, courses, events, coupons, claims, tickets, reviews, payouts
- **Availability & time-off** scheduling for experts
- **Certificates** auto-issued on course completion
- **Analytics dashboards** for admin & expert
- **Search / filter / pagination** on every list
- **Notification center** with unread badge and mark-all-read
- **CSV export**, **audit log**, **rate limiting**, **input validation**, **file-type whitelisting**
- **Dark mode** persisted per user
- **Keyboard shortcuts** (`Esc` closes modals, `/` focuses search)

## 📦 Requirements
- Node.js 18+
- MySQL 8+ (or MariaDB 10.5+)
